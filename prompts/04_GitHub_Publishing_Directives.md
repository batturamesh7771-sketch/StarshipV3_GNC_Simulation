# Prompt 04: GitHub Architecture & Publishing Directives

## Objective
Structure the entire project into a clean, professional, modular repository layout and publish it to the user's GitHub profile (`https://github.com/batturamesh7771-sketch/StarshipV3_GNC_Simulation`).

---

## Directory Organization Mandate
- `/src`: All MATLAB `.m` source files.
- `/docs`: Detailed mathematical derivations, flight event timeline, and software architecture diagrams.
- `/data`: Telemetry flight logs and vehicle database JSON specifications.
- `/config`: GNC simulation and vehicle configuration JSON files.
- `/results`: High-resolution visual captures (`StarshipV3_3D_Mission_Success.png`, `StarshipV3_Ascent_Telemetry.png`).
- `/prompts`: Chronological index of all orchestration prompts and directives.
- `README.md`: Master documentation with GitHub badges, system architecture, LaTeX physics equations, quickstart steps, and author profile.
- `LICENSE`: Official MIT License.
- `.gitignore`: Standard MATLAB and OS ignore rules.
- `run_simulation.bat`: One-click Windows batch launcher.
